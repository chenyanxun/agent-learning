## 目录规范

**每周一个文件夹，每天一个子文件夹：**

```text
agent-learning/
├── week01-python-basics/
│   ├── day01/          # README.md + exercises.py + NOTES.md
│   ├── day02/
│   └── ...
├── week02-mini-agent/
│   ├── day01/
│   └── ...
└── ...
```

进入对应 `dayXX/README.md` 按任务执行。
