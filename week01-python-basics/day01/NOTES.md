# Day 1 笔记

## TS vs Python

| TypeScript | Python | 我的理解 |
|:---|:---|:---|
| `npm install` | `pip install` | 安装依赖 |
| `const x = 1` | `x = 1` | 定义变量 |
| `` `Hello, ${name}` `` | `f"Hello, {name}"` | 变量 |
| `arr.map(x => x * 2)` | `[x * 2 for x in arr]` | 遍历 |
| `{ key: value }` | `{"key": value}` | 键值对 |
